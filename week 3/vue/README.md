# Vue.js Approval Management Frontend (Week 3)

Single Page Application built with **Vue 3**, **Vite**, **TypeScript**, and **Axios** consuming the **Week 2 Python + FastAPI Approval API**.

## 🛠 Tech Stack
- Vue 3 (Composition API & `<script setup>`)
- Vite
- Vue Router & Navigation Guards
- Axios (Request & Response Interceptors)
- TypeScript (Strict Interfaces & Types)
- Vitest & Vue Test Utils

## ⚙️ Environment Configuration
API base URL configured in `.env`:
```env
VITE_API_BASE_URL=http://localhost:8000/api/v1
```

## 🚀 How to Run
```bash
npm install
npm run dev
```
App runs at `http://localhost:5173`.

## 🧪 Testing
```bash
npm run test
```
